# CJ Engineering — Take-Home Exercises

Take-home assignments for CJ's specialty engineering roles. If you are interviewing with
us, your recruiter will tell you which one applies to you and when it is due.

| Role | Assignment |
|---|---|
| Senior Platform Engineer | [`senior-platform-engineer/`](senior-platform-engineer/) |
| Platform Engineer (SE3) | [`platform-engineer-se3/`](platform-engineer-se3/) |
| Software Engineer 2, Platform | [`software-engineer-2-platform/`](software-engineer-2-platform/) |
| Security Engineer | [`security-engineer/`](security-engineer/) |

Each folder is self-contained. The Security Engineer assignment includes a
`security-review/` bundle of code and configuration you will work on.

## How to submit

Clone or download this repository, work in a copy, and send your deliverables back to your
recruiter. Do not open a pull request against this repository.

## On AI

AI tools are allowed. Each assignment asks you to include an `ai-usage.md` describing what you
used and what you verified yourself. We are not evaluating whether you used AI; we are
evaluating whether you used it responsibly. Expect to walk through your reasoning live in a
later conversation, without it.
